# CrimeDetector

Este proyecto es mi proyecto final para la materia de **Aplicaciones Web Orientedas a Objetos** de 5to cuatrimestre de TSU Desarrollo de Software Multiplaforma.

## Proposito

El proposito o función de la pagina ser una base de reportes de crimenes en la ciudad de Villahermosa en base con el modelo *crowdsourcing* para ayudar en la toma de decisiones de seguridad en la ciudad.

## Consideraciones al clonar el proyecto

En el archivo *config.php* se necesitan las API keys de **Google Cloud Platform** y **MLH** para las APIs de autentificación.

También requiere de importar la libreria **google/apiclient** de PHP con composer en la carpeta **/libs** para que la API de autenticación de Google funcione correctamente
